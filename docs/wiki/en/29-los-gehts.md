# 29 · Getting started — the first minutes

*For users.* What you see after signing in, and how you get to your first workspace.

## Signing in ✅

You open the address your administrators gave you and land on the **central sign-in**. Your company
account applies there, i.e. the same name and password as elsewhere. If your group requires a second
factor, the sign-in asks for it ([chapter 30](30-mein-konto.md)).

If OTA is left unused for a while, it signs you out. By default that is eight hours without any
activity ([chapter 3](03-arbeitsplatz.md#automatic-sign-out-)).

## The sidebar ✅

| Entry | What for |
|---|---|
| **Start** | your running sessions and everything you can start |
| **News** | announcements from the administrators. A badge with a number shows how many are new |
| **My files** | files into your workspace and out again ([chapter 31](31-dateien.md)) |
| **Help** | this handbook |
| **My account** | password, second factor, language ([chapter 30](30-mein-konto.md)) |
| ◐ ☀ ☾ | theme: like the system, light or dark |
| **Sign out** | signs you out. Your workspaces keep running |

At the top right you switch between **DE** and **EN**.

## The start page ✅

From top to bottom:

- **Your sessions:** what is running or paused right now. A click on a card opens it again.
- **Other applications:** web applications that run elsewhere and use the same sign-in. A click
  opens them in a tab of their own.
- **On your desktop:** shortcuts for your computer, so an application starts like a local program
  ([chapter 3](03-arbeitsplatz.md#pinning-to-the-desktop-)).
- **Your apps:** everything you can start. Each tile shows how many cores and how much memory it gets.

With the pencil ✎ at the top right of a tile you give it a name of your own. Only you see it.

## Workspace or single application

There are two kinds of tiles:

| | Workspace | Single application |
|---|---|---|
| What you get | a whole Linux desktop with several programs | exactly one program, filling the screen |
| Recognisable by | "… apps in one container" under the description | just the program's name |
| Typical | development, several tools side by side | a browser, an office application |

In both cases your **home** (`/home/…`) is kept, even when the container ends.

## The first start ✅

1. Click **Start**.
2. A **progress bar** on the tile shows what is happening ("Starting container", "Desktop
   starting" …) and how long it has taken so far. The first time takes a little longer because
   your home is being created. After that it is quicker.
3. A **single application** then opens in a new tab. For a **workspace**, you choose the
   application you want to open at the top of the start page.
4. Click into the picture once so the keyboard arrives there.

The start page stays in the first tab. You switch between your applications as between windows.
